# Software Defined Networking (SDN) - Class Activities

This repository contains four practical activities completed as part of the Software Defined Networking coursework.

## Activities

### Activity 1: SDN-Based Network Policy Enforcement
A Python-based network policy engine using ONOS REST APIs to monitor switch statistics and apply ICMP blocking flow rules.

### Activity 2: Broadcast Storm Protection using ONOS
A Java-based ONOS application implementing MAC learning, duplicate broadcast detection and temporary packet drop rules.

### Activity 3: Network Slicing using VLAN and QoS
Logical traffic separation using VLAN 100 and VLAN 200, with separate QoS queues configured in Open vSwitch.

### Activity 4: Intent-Based Networking using ONOS
A bandwidth-constrained host-to-host intent implemented over a diamond topology, demonstrating automatic rerouting after link failure.

## Technologies Used

- ONOS SDN Controller
- Mininet
- Open vSwitch
- OpenFlow 1.3
- Python
- Java
- Maven
- VLAN and QoS
- REST APIs
- Linux
